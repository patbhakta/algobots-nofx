```python
def fetch_stock_data(tickers: list[str], period: str = "3mo") -> dict[str, pd.DataFrame]
```

### 2. indicators.py
```python
def calculate_rsi(prices: pd.Series, period: int = 14) -> pd.Series
def calculate_macd(prices: pd.Series) -> tuple[pd.Series, pd.Series, pd.Series]  # MACD, signal, histogram
def calculate_bollinger(prices: pd.Series, period: int = 20) -> tuple[pd.Series, pd.Series, pd.Series]  # upper, middle, lower
def calculate_sma(prices: pd.Series, period: int = 20) -> pd.Series
def calculate_ema(prices: pd.Series, period: int = 20) -> pd.Series
```

### 3. analyzer.py
```python
def analyze_stock(ticker: str, data: pd.DataFrame) -> StockAnalysis
```

## Kestra Flow

```yaml
id: algobots-daily-analysis
namespace: algobots
description: "Daily stock technical analysis — fetch, calculate, report"

triggers:
  - id: market-open
    type: io.kestra.plugin.core.trigger.Schedule
    cron: "30 13 * * 1-5"  # 9:30 AM ET (13:30 UTC), weekdays only

inputs:
  - id: tickers
    type: ARRAY
    itemtype: STRING
    defaults: ["AAPL", "GOOGL", "TSLA"]

tasks:
  - id: fetch
    type: io.kestra.plugin.scripts.python.Commands
    namespaceFiles:
      enabled: true
    commands:
      - python src/algobots/fetcher.py --tickers "{{ inputs.tickers }}" --output data.json

  - id: indicators
    type: io.kestra.plugin.scripts.python.Commands
    namespaceFiles:
      enabled: true
    inputFiles:
      data.json: "{{ outputs.fetch.outputFiles['data.json'] }}"
    commands:
      - python src/algobots/indicators.py --input data.json --output indicators.json
    outputFiles:
      - "indicators.json"

  - id: analyze
    type: io.kestra.plugin.scripts.python.Commands
    namespaceFiles:
      enabled: true
    inputFiles:
      indicators.json: "{{ outputs.indicators.outputFiles['indicators.json'] }}"
    commands:
      - python src/algobots/analyzer.py --input indicators.json --output analysis.json
    outputFiles:
      - "analysis.json"

  - id: report
    type: io.kestra.plugin.scripts.python.Commands
    namespaceFiles:
      enabled: true
    inputFiles:
      analysis.json: "{{ outputs.analyze.outputFiles['analysis.json'] }}"
    commands:
      - python src/algobots/reporter.py --input analysis.json --output report.md
    outputFiles:
      - "report.md"
```

## Library Choices

| Library | Purpose | Why |
|---------|---------|-----|
| yfinance | Stock data | Free, no API key, reliable |
| pandas | Data manipulation | Industry standard |
| numpy | Math operations | Dependency of pandas |
| Manual indicators | RSI, MACD, etc. | No extra deps, full control, testable |

**No pandas-ta** — manual implementation is cleaner, more testable, and avoids dependency bloat.
