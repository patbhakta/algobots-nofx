## What this slice landed

- **`pipeline/flows/algobots-ingest.yaml`** — the Kestra spine mirroring
  `book-ingest.yaml`'s shape: one deterministic stage (`register -> snapshot
  -> lineage -> incremental index -> status gate`), bounded retries
  (`constant`, 3 attempts, 30s interval) made safe by version-keyed
  idempotent writes, and nonzero gate exits (3 FAILED, 4 PARTIAL) that halt
  the flow — slop never advances. Snapshot-before-index ordering is the
  stage's law: parsing reads only the immutable snapshot, never the live
  vault.
- **`tests/packets/A14/test_acceptance.py`** — AC1–AC5 as executable
  end-to-end cases driving the exact surface the pipeline stage drives
  (`Ingestor.register_source` -> `SearchService.run_sync` -> search /

  those cases plus the unit lanes, emitting
  `artifacts/A14/acceptance.json` (PASS / FAIL / BLOCKED + evidence paths)

- **`tests/packets/A14/demo.py`** — the offline demo (`make demo-A14`

## Limitations (stated honestly)

- **Markdown-first.** Only `.md` notes become evidence chunks
  (section-aligned, never fixed-size). Non-Markdown assets are queued with a
  named capability; **zero processors ship** and none is claimed — OCR /
  pdf-text / table-parse remain future slices behind
  `ApprovedProcessors`.
- **Failed extraction is terminal data, never content.** A failed or
  processor-less asset surfaces on the sources screen and stays
  queryable-as-failed; no text is ever substituted.
- **Edit cost is per-document.** Chunk ids are keyed by the version content
  hash, so any edit re-embeds that document's chunks (a rename re-embeds
  nothing). Per-section incremental re-embedding is a possible later
  refinement, not a current claim.
- **Removal propagation is synchronous-local.** The ≤ 60s window is proven
  with tombstone + ACL revocation + cache/index invalidation on one node;
  a warm result cache may serve stale hits up to the 30s TTL (asserted
  strictly inside the window). A negative (empty) cache entry is TTL-bounded
  rather than purgeable; an explicit ACL restore may therefore take up to
  TTL to re-expose on a warm reader.
- **Local deterministic embedder.** The default embedder is a seeded
  hashed bag-of-tokens projection (BM25 + vector surface, zero external
  spend). It is not semantic; a model-backed embedder slots in behind the
  same callable shape and re-embeds under its own artifact key.
- **Flow stage is single-node.** The Kestra spine runs one shell stage per
  sync; no distributed orchestration, scheduling, or vault watching is
  claimed. Source removal/tombstones are operator actions through the
  `/api/knowledge` surface, never part of the flow.
